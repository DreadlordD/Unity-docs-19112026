    Add a custom button to the toolbar

    If you often run the same command from a menu, add a button to the Unity Editor toolbar to run it with one click. For example, you can create a button that opens the Project Settings window.

    You define a toolbar button in an Editor script. The script contains a static method that returns a MainToolbarButton, and the MainToolbarElement attribute registers that method with the toolbar. The Editor calls the method when it creates the toolbar. The class doesn’t need to inherit from MonoBehaviour.

    This page creates the button in stages. Each stage is a complete script with its own menu path, so you can display each version of the button separately. To run more complex tasks from the toolbar, refer to Add a toolbar button that creates GameObjects.

    Create the button script

    Toolbar scripts use the UnityEditor API, so they must be in a folder called Editor or in an Editor-only assembly. To learn more about the Editor folder, refer to Reserved folder name reference.

    The following script adds a button that opens the Project Settings window.

    To create a basic button:

    1. In the Project window, create a folder called Editor in the Assets folder if you don’t already have one.

    2. In the Editor folder, right-click and select Create > Scripting > Empty C# Script.

    3. Name the script ProjectSettingsButton.cs.

    4. Open the script and replace its contents with the following code:

      using UnityEditor;
using UnityEditor.Toolbars;

public class ProjectSettingsButton
{
    [MainToolbarElement("Example/Project Settings")]
    public static MainToolbarElement CreateProjectSettingsButton()
    {
        // Define the text that the button displays.
        MainToolbarContent content = new MainToolbarContent("Project Settings");
        // Open the Project Settings window when you select the button.
        return new MainToolbarButton(content, () => SettingsService.OpenProjectSettings());
    }
}

      The script contains the following parts:

      • The MainToolbarElement attribute takes a path that identifies the button. The path also sets where the button appears in the toolbar context menu. In this example, the button appears as Project Settings in the Example section, and it docks in the left section of the toolbar by default.
      • The method’s return type is MainToolbarElement. This class has the same name as the attribute, but it’s the base class for all toolbar controls.
      • MainToolbarContent defines what the button displays. In this example, the button displays the text Project Settings.
      • MainToolbarButton takes the content and the method to run when you select the button.

    5. Save the script.

    After the Editor compiles the script, the Project Settings button is available in the toolbar context menu. The toolbar doesn’t display the button yet.

    Display the button in the toolbar

    The Editor hides custom toolbar controls by default, so you must display the button in the toolbar to use it.

    For more information about how to show, hide, and move controls, refer to Customize the toolbar.

    To display and use the button:

    1. In the Editor, right-click an empty area of the toolbar, or select the More (⋮) menu, to open the toolbar context menu.
    2. Select Example > Project Settings to display the Project Settings button.
    3. Select Project Settings to open the Project Settings window.

    The Project Settings button appears in the left section of the toolbar. To move the button, hold Ctrl (macOS: Cmd) and drag it to a new location.

    Add an icon and a tooltip

    A button can display text, an icon, or both. When you hover over a button, its tooltip describes what the button does. To add an icon and a tooltip, use the MainToolbarContent constructor that takes text, an icon, and a tooltip.

    The following script changes the Project Settings button to display an icon and the text Project Settings, and adds a tooltip that appears when you hover over the button.

    To add an icon and a tooltip to the button:

    1. Replace the contents of ProjectSettingsButton.cs with the following code:

      using UnityEditor;
using UnityEditor.Toolbars;
using UnityEngine;

public class ProjectSettingsButton
{
    [MainToolbarElement("Example/Project Settings (Icon)")]
    public static MainToolbarElement CreateProjectSettingsButton()
    {
        // Get the built-in settings icon.
        Texture2D icon = EditorGUIUtility.IconContent("SettingsIcon").image as Texture2D;

        // Display the icon and text, and show a tooltip when you hover over the button.
        MainToolbarContent content = new MainToolbarContent("Project Settings", icon, "Open the Project Settings window");
        return new MainToolbarButton(content, () => SettingsService.OpenProjectSettings());
    }
}

      This code gets the built-in settings icon with EditorGUIUtility.IconContent and casts its image to a Texture2D.

      To display only the icon, pass the icon and the tooltip without text: new MainToolbarContent(icon, "Open the Project Settings window"). To use your own icon, load it as a Texture2D and pass it to MainToolbarContent.

    2. Save the script.

    3. In the Editor, right-click an empty area of the toolbar and select Example > Project Settings (Icon) to display the Project Settings button.

    4. Hover over the button to display its tooltip.

    The button displays the settings icon and the text Project Settings, and the tooltip appears when you hover over the button.

    Set the default position

    By default, a custom button appears in the left section of the toolbar. To set where the button first appears, use the following properties of the MainToolbarElement attribute:

    • defaultDockPosition: The section of the toolbar where the button appears. Use MainToolbarDockPosition.Left, Middle, or Right.
    • defaultDockIndex: The order of the button in that section. The Editor reserves values of 100 and lower for built-in controls, so use a value higher than 100.

    To place the button in the right section of the toolbar:

    1. Replace the contents of ProjectSettingsButton.cs with the following code:

      using UnityEditor;
using UnityEditor.Toolbars;
using UnityEngine;

public class ProjectSettingsButton
{
    [MainToolbarElement("Example/Project Settings (Docked)",
        defaultDockPosition = MainToolbarDockPosition.Right,
        defaultDockIndex = 200)]
    public static MainToolbarElement CreateProjectSettingsButton()
    {
        // Get the built-in settings icon.
        Texture2D icon = EditorGUIUtility.IconContent("SettingsIcon").image as Texture2D;

        // Display the icon and text, and show a tooltip when you hover over the button.
        MainToolbarContent content = new MainToolbarContent("Project Settings", icon, "Open the Project Settings window");
        return new MainToolbarButton(content, () => SettingsService.OpenProjectSettings());
    }
}

      defaultDockPosition = MainToolbarDockPosition.Right places the button in the right section of the toolbar. This property sets only the position where the button first appears. You can still move the button anywhere in the toolbar.

    2. Save the script.

    3. In the Editor, right-click an empty area of the toolbar and select Example > Project Settings (Docked) to display the Project Settings button.

    The Project Settings button appears in the right section of the toolbar.
