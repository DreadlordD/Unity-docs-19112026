    Display progress bars on nodes

    Show which node your graph tool evaluates and how far that node has progressed.

    Each node has an accent bar along its upper border that can display a progress fill. Use the fill to report execution feedback while your graph tool runs, so users can follow which node is active and how much work remains.

    Use a fill amount when you know how much of the work is complete, such as a node that processes a known number of items. Use a looping animation when a node is active but the amount of work left is unknown.

    This page covers how to display progress on nodes only. For information on how visualization contexts work, refer to Introduction to graph visualization.

    Prerequisites

    Before you display progress on nodes, you need a graph class that Unity can open in the Graph window. If you haven’t created one yet, follow the instructions in Implement a graph tool.

    Create a visualization context

    A visualization context owns all the progress feedback you apply, so you can remove it in a single call.

    To create a visualization context for a graph:

    1. Call Registry.CreateVisualizationContext with the graph’s identifier, available from Graph.ID. For a node inside a nested graph, pass the identifier of the root graph.
    2. Store the context for the whole run, for example in a field, and dispose of it when the run finishes.
    readonly Context m_Context;

public NodeVisualizationExamples(Graph graph)
{
    // Pass Graph.ID. For a node inside a nested graph, pass the ID of the root graph.
    m_Context = Registry.CreateVisualizationContext(graph.ID);
}

// Call Dispose when the run finishes. Unity then removes every
// visual that the context applied to the graph.
public void Dispose() => m_Context.Dispose();

    To annotate a node, call Context.GetNodeReference with the node’s identifier, available from INode.ID, to get a NodeReference for that node.

    When you dispose of the context, Unity removes every progress bar the context applied. To clear the feedback but continue to use the context, call Context.ClearAllVisualization instead.

    Note: When you enter or exit Play mode, Unity releases every visualization context. Create the context after the mode change, and don’t reuse a context from before it.

    Show determinate progress on a node

    To display a progress bar that reflects how much work a node has completed:

    1. Get a NodeReference for the node from the context.
    2. Set NodeReference.FillAmount to the percentage complete, as a value from 0 to 100.
    3. Set FillAmount again each time the progress changes.
    public void ReportProgress(INode node, float completedFraction)
{
    NodeReference nodeRef = m_Context.GetNodeReference(node.ID);

    // A positive value fills the accent bar from left to right.
    nodeRef.FillAmount = completedFraction * 100f;
}

public void ReportReverseProgress(INode node, float completedFraction)
{
    NodeReference nodeRef = m_Context.GetNodeReference(node.ID);

    // A negative value fills the accent bar from right to left.
    nodeRef.FillAmount = -completedFraction * 100f;
}

    The accent bar fills from left to right in proportion to the value. A negative value from -100 to 0 fills the bar from right to left instead, which suits nodes that undo or roll back work. Unity clamps values outside the range -100 to 100.

    To hide the bar, set FillAmount to 0 .

    Show that a node is active without progress

    When a node is active but you can’t measure how much work is left, display a looping animation instead of a fill.

    To display a looping animation on a node:

    1. Get a NodeReference for the node from the context.
    2. Call Context.Motion.Play with the reference. Optionally pass an animationSpeed multiplier, which defaults to 1. Higher values move the animated segment faster.
    public void MarkNodeRunning(INode node)
{
    NodeReference nodeRef = m_Context.GetNodeReference(node.ID);

    // The animation loops until you call Stop or Pause, and overrides FillAmount.
    m_Context.Motion.Play(nodeRef, animationSpeed: 2f);
}

    The animation loops until you stop or pause it. While it plays, it overrides any fill amount you set on the node.

    Note: Play throws an ArgumentException if the reference doesn’t correspond to a node in the current session.

    Pause or stop the progress display

    To freeze the animation and leave the accent bar visible, call Context.Motion.Pause and pass the node reference. Call Play again to resume it.

    To end the animation, call Context.Motion.Stop with the node reference. This hides the accent bar unless you set a fill amount before you play the animation. In this case, the bar stays visible at that fill amount.

    public void PauseNode(INode node)
{
    // Freezes the animation and leaves the accent bar visible.
    m_Context.Motion.Pause(m_Context.GetNodeReference(node.ID));
}

public void StopNode(INode node)
{
    // Hides the accent bar. If you set a fill amount before you play the
    // animation, the bar stays visible at that fill amount instead.
    m_Context.Motion.Stop(m_Context.GetNodeReference(node.ID));
}

    If you pause a node that has no active animation, no effect is visible.

    Reset a node to its default appearance

    To remove the progress bar from a single node, call NodeReference.ClearCustomization. This removes the fill amount and stops any looping animation on that node.

    public void ResetNode(INode node)
{
    // Removes the fill amount and stops any animation on the node.
    m_Context.GetNodeReference(node.ID).ClearCustomization();
}

    The node returns to its default appearance, and the accent bar is hidden.

    To hide the progress bars on every node but keep the values, set Context.NodeCustomizationEnabled to false. Unity restores the values when you set the property back to true.
