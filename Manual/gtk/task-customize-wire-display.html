    Customize wire appearance

    Customize the appearance of wires in a graph.

    You can change the width, opacity, and dash pattern of a wire, and you can animate a wire to highlight an active data path.

    Use these overrides to make a dense graph easier to read, to de-emphasize connections that aren’t relevant, or to show which path data takes in your graph.

    This page covers the appearance of existing wires only. For information on how to create connections between nodes, refer to Connect nodes in your graphs.

    Prerequisites

    Before you customize wire appearance, you need a graph class with at least two connected nodes. If you haven’t created a graph tool yet, follow the instructions in Implement a graph tool.

    Modify the appearance of the wires

    There are two ways to override the width, opacity, and dash pattern of a wire, and they differ in which object owns the override:

    • Set the properties on the wire itself when the appearance is part of how the graph reads as the user edits it.
    • Set the properties through a visualization context when the appearance represents a temporary state, such as a run in progress. When you dispose of the context, Unity removes every override the context applied.

    Neither approach saves the overrides to the graph asset. Apply them again each time the graph loads.

    Note: You can’t set the color of an individual wire. Wire color comes from the data type of the port that the wire connects. To define the color for a custom data type, register the type in a DataTypeStyleMapper subclass. Don’t use it to override the style of a built-in type, because that leads to inconsistent visuals in the Graph canvas.

    Set the properties on a wire

    To override the appearance of a single wire:

    1. Get the output and input ports that the wire connects, for example with INode.GetOutputPortByName and INode.GetInputPortByName.
    2. Call Graph.GetWire, and pass the two ports. Check the result for null because the method returns null when the ports aren’t connected.
    3. Set WidthOverride, Opacity, or IsDashed on the returned wire.
    public void StyleWire(Graph graph, INode fromNode, INode toNode)
{
    IPort outputPort = fromNode.GetOutputPortByName("result");
    IPort inputPort = toNode.GetInputPortByName("a");

    // GetWire returns null when the two ports aren't connected.
    Wire wire = graph.GetWire(outputPort, inputPort);
    if (wire == null)
        return;

    // Set to 0 to restore the default thickness.
    wire.WidthOverride = 4f;
    // Clamped to the range 0 to 1.
    wire.Opacity = 0.5f;
    wire.IsDashed = true;
}
readonly Context m_Context;

public WireVisualizationExamples(Graph graph)
{
    m_Context = Registry.CreateVisualizationContext(graph.ID);
}

// When you dispose of the context, Unity removes these overrides.
public void Dispose() => m_Context.Dispose();

public void StyleWireThroughContext(IPort outputPort, IPort inputPort)
{
    WireReference wire = m_Context.GetWireReference(outputPort.ID, inputPort.ID);
    wire.WidthOverride = 4f;
    wire.Opacity = 0.5f;
    wire.IsDashed = true;
}

    The wire redraws with the values you set. When you set WidthOverride to 0, Unity removes the override, so the wire reverts to the default thickness from the graph canvas style. Unity clamps Opacity to the range 0 to 1, where 0 is fully transparent and 1 is fully opaque.

    A single wire covers the whole connection between two ports, even one that passes through a portalA connection point that works in pairs and replaces visible wires with wireless pathways to reduce visual clutter. They respect the same constraints as the wires they replace.
    See in Glossary    .

    Set the properties through a visualization context

    To override the appearance of a wire through a visualization context:

    1. Call Registry.CreateVisualizationContext, and pass the graph’s identifier, available from Graph.ID.
    2. Call Context.GetWireReference, and pass the identifiers of the output port and the input port, available from IPort.ID.
    3. Set WidthOverride, Opacity, or IsDashed on the returned WireReference.
    readonly Context m_Context;

public WireVisualizationExamples(Graph graph)
{
    m_Context = Registry.CreateVisualizationContext(graph.ID);
}

// When you dispose of the context, Unity removes these overrides.
public void Dispose() => m_Context.Dispose();

public void StyleWireThroughContext(IPort outputPort, IPort inputPort)
{
    WireReference wire = m_Context.GetWireReference(outputPort.ID, inputPort.ID);
    wire.WidthOverride = 4f;
    wire.Opacity = 0.5f;
    wire.IsDashed = true;
}

    The properties behave the same way as on a wire, but the context owns the values. When you dispose of the context, Unity removes every override the context applied.

    Note: Assign the WireReference to a local variable before you set a property on it. WireReference is a struct, so the compiler rejects an assignment to a property on the value that GetWireReference returns directly.

    Remove the overrides from a wire

    To remove the width, opacity, and dash overrides from one wire, call WireReference.ClearCustomization.

    public void ResetWire(IPort outputPort, IPort inputPort)
{
    WireReference wire = m_Context.GetWireReference(outputPort.ID, inputPort.ID);

    // Removes the width, opacity, and dash overrides from the wire.
    wire.ClearCustomization();
}

    The wire returns to the appearance that the graph canvas style defines.

    To hide the overrides on every wire but not discard the wires themselves, set Context.WireCustomizationEnabled to false. Unity preserves the values and restores them when you set the property back to true.

    Control the wire animation

    A flow animation moves a highlighted segment along a wire to draw attention to an active data path. Animation is available only through a visualization context, so there’s no equivalent on a wire.

    To animate a wire:

    1. Get a WireReference for the connection from the context.
    2. Call Context.Motion.Play, and pass the reference. Optionally, pass an animationSpeed multiplier, which defaults to 1. Higher values move the segment faster.
    public void AnimateWire(IPort outputPort, IPort inputPort)
{
    WireReference wire = m_Context.GetWireReference(outputPort.ID, inputPort.ID);

    // The animation loops until you stop or pause it.
    m_Context.Motion.Play(wire, animationSpeed: 2f);
}

public void PauseWireAnimation(WireReference wire)
{
    // Freezes the animation and keeps the width, opacity, and dash overrides.
    m_Context.Motion.Pause(wire);
}

public void StopWireAnimation(WireReference wire)
{
    m_Context.Motion.Stop(wire);
}

    The animation loops until you pause or stop it.

    To freeze the animation at its current position, call Context.Motion.Pause. This keeps the width, opacity, and dash overrides applied. Call Context.Motion.Play again on the same wire to resume. To end the animation, call Context.Motion.Stop.

    If you pause a wire that has no active animation, no effect is visible.
