    Highlight GameObjects in the Hierarchy window

    In a large scene, it can be difficult to find the GameObjects you work with most. To make those GameObjects stand out, change how their rows look in the Hierarchy window. For example, you can automatically color the rows of every GameObject that has an Enemy component, or display a star icon for every GameObject that has the Favorite tag.

    This tutorial explains how the Hierarchy window displays items, which applies to every script that changes the Hierarchy window. To learn about other changes you can make, refer to Extending the Hierarchy window.

    Prerequisites

    Before you begin, complete the following steps:

    • Disable the Use Legacy Hierarchy setting, if you enabled it. For more information, refer to Switch to the legacy Hierarchy window.
    • In the Project window, create the Assets/Scripts and Assets/Editor/HierarchyExtensions folders. The scripts on this page load their style sheets from Assets/Editor/HierarchyExtensions.

    How the Hierarchy window displays items

    The Hierarchy window displays the contents of your scenes in a view. The HierarchyView class represents this view. The view contains one node for each scene, GameObject, or other item. Each visible row of the view is a HierarchyViewItem, which is a visual elementA node of a visual tree that instantiates or derives from the C# VisualElement class. You can style the look, define the behaviour, and display it on screen as part of the UI. More info
    See in Glossary     bound to one node. A node type handler manages each type of node. For example, HierarchyGameObjectHandler manages GameObject nodes and returns the GameObject that a node represents.

    To change how the Hierarchy window looks, subscribe to static events of the HierarchyWindow class in an Editor script. Subscribe in a method that has the InitializeOnLoadMethod attribute, so that the Editor subscribes again each time it reloads your scripts. The Unity Editor raises the following events:

    Event When the Unity Editor raises the event Typical use
    BindView When a Hierarchy window creates its view. Add style sheets to the view or subscribe to events of that view only.
    BindViewItem Each time a row displays an item. Change the style of the row or add elements to the row.
    UnbindViewItem Each time a row stops displaying an item. Remove elements that you added in BindViewItem.
    UnbindView When a Hierarchy window destroys its view. Unsubscribe from events of the view.

    The Hierarchy window creates only enough rows to fill the window, and reuses them as you scroll, expand, and collapse items. A row that displayed an enemy can display a different GameObject the next time the Editor raises BindViewItem for it. The method that you subscribe to BindViewItem must set the state of the row for every item, including items that you don’t want to change. Otherwise, a reused row can keep the style or elements of the item it displayed before.

    Create an Enemy component

    The scripts on this page color the rows of GameObjects that have an Enemy component. The component marks GameObjects as enemies and has no behavior of its own. You can use any component of your own instead.

    To create the Enemy component:

    1. In the Assets/Scripts folder, right-click and select Create > Scripting > Empty C# Script.

    2. Name the script Enemy.cs.

    3. Open the script and replace its contents with the following code:

      using UnityEngine;

// Marks a GameObject as an enemy. The component has no behavior of its own.
public class Enemy : MonoBehaviour
{
}

    4. Save the script.

    5. In the Hierarchy window, select a GameObject.

    6. In the Inspector window, select Add Component > Scripts > Enemy.

    The selected GameObject now has the Enemy component attached.

    Color the rows of enemies

    The following script adds a style sheet to the Hierarchy window, then adds a Unity style sheet (USS) class to the row of each enemy. The style sheet sets the background color of rows that have the class.

    To color the rows of enemies:

    1. In the Assets/Editor/HierarchyExtensions folder, right-click and select Create > UI Toolkit > Style Sheet (USS).

    2. Name the style sheet EnemyRowColor.uss.

    3. Open the style sheet and replace its contents with the following code:

      .gameobject--enemy {
    background-color: #7a2d2d;
}

    4. In the HierarchyExtensions folder, right-click and select Create > Scripting > Empty C# Script.

    5. Name the script EnemyRowColor.cs.

    6. Open the script and replace its contents with the following code:

      using Unity.Hierarchy;
using Unity.Hierarchy.Editor;
using UnityEditor;
using UnityEngine;
using UnityEngine.UIElements;

public static class EnemyRowColor
{
    const string k_StyleSheetPath = "Assets/Editor/HierarchyExtensions/EnemyRowColor.uss";
    const string k_EnemyUssClassName = "gameobject--enemy";

    [InitializeOnLoadMethod]
    static void Initialize()
    {
        HierarchyWindow.BindView += OnBindView;
        HierarchyWindow.BindViewItem += OnBindViewItem;
    }

    // Runs once each time a Hierarchy window creates its view.
    static void OnBindView(HierarchyWindow window, HierarchyView view)
    {
        StyleSheet styleSheet = AssetDatabase.LoadAssetAtPath<StyleSheet>(k_StyleSheetPath);
        view.styleSheets.Add(styleSheet);
    }

    // Runs each time a row displays an item.
    static void OnBindViewItem(HierarchyWindow window, HierarchyView view, HierarchyViewItem item)
    {
        // The row can display a different item each time, so remove the class first.
        // Rows can also display scenes and other items that aren't GameObjects.
        item.RowContainer.RemoveFromClassList(k_EnemyUssClassName);

        if (item.Handler is not HierarchyGameObjectHandler handler)
        {
            return;
        }

        GameObject gameObject = handler.GetGameObject(item.Node);
        if (gameObject == null)
        {
            return;
        }

        // Add the class to enemy rows only.
        if (gameObject.TryGetComponent<Enemy>(out _))
        {
            item.RowContainer.AddToClassList(k_EnemyUssClassName);
        }
    }
}

      The script contains the following parts:

      • The InitializeOnLoadMethod attribute runs Initialize when the Editor loads the script. Initialize subscribes to the BindView and BindViewItem events.
      • OnBindView loads the style sheet with AssetDatabase.LoadAssetAtPath and adds it to the view.
      • RowContainer is the element that draws the background of the row. OnBindViewItem removes the enemy class from it first, so a reused row never keeps the color of an enemy it displayed before.
      • OnBindViewItem then checks that the item is a GameObject and gets the GameObject from the node type handler. AddToClassList adds the class if the GameObject has an Enemy component.

    7. Save the script.

    The rows of GameObjects that have an Enemy component now display a red background in the Hierarchy window. If the rows don’t change color, or the Console window displays an ArgumentNullException for the styleSheet parameter, check that the path in k_StyleSheetPath matches the location of EnemyRowColor.uss. In the script from Match the Editor theme, check k_DarkStyleSheetPath and k_LightStyleSheetPath instead. The exception also stops the BindView handlers of scripts that subscribed later, so their style sheets don’t load until you fix the path.

    Match the Editor theme

    A color that has good contrast in the dark Editor theme can have poor contrast in the light theme. To choose a color for each theme, create a style sheet for each theme and load the one that matches the current theme.

    To match the color of enemy rows to the Editor theme:

    1. In the HierarchyExtensions folder, right-click and select Create > UI Toolkit > Style Sheet (USS).

    2. Name the style sheet EnemyRowColor_dark.uss.

    3. Open the style sheet and replace its contents with the following code:

      .gameobject--enemy {
    background-color: #7a2d2d;
}

    4. In the same folder, right-click and select Create > UI Toolkit > Style Sheet (USS).

    5. Name the style sheet EnemyRowColor_light.uss.

    6. Open the style sheet and replace its contents with the following code:

      .gameobject--enemy {
    background-color: #8f6464;
}

    7. Replace the contents of EnemyRowColor.cs with the following code:

      using Unity.Hierarchy;
using Unity.Hierarchy.Editor;
using UnityEditor;
using UnityEngine;
using UnityEngine.UIElements;

public static class EnemyRowColor
{
    const string k_DarkStyleSheetPath = "Assets/Editor/HierarchyExtensions/EnemyRowColor_dark.uss";
    const string k_LightStyleSheetPath = "Assets/Editor/HierarchyExtensions/EnemyRowColor_light.uss";
    const string k_EnemyUssClassName = "gameobject--enemy";

    [InitializeOnLoadMethod]
    static void Initialize()
    {
        HierarchyWindow.BindView += OnBindView;
        HierarchyWindow.BindViewItem += OnBindViewItem;
    }

    static void OnBindView(HierarchyWindow window, HierarchyView view)
    {
        // Load the style sheet that matches the current Editor theme.
        string styleSheetPath = EditorGUIUtility.isProSkin ? k_DarkStyleSheetPath : k_LightStyleSheetPath;
        StyleSheet styleSheet = AssetDatabase.LoadAssetAtPath<StyleSheet>(styleSheetPath);
        view.styleSheets.Add(styleSheet);
    }

    static void OnBindViewItem(HierarchyWindow window, HierarchyView view, HierarchyViewItem item)
    {
        // The row can display a different item each time, so remove the class first.
        item.RowContainer.RemoveFromClassList(k_EnemyUssClassName);

        if (item.Handler is not HierarchyGameObjectHandler handler)
        {
            return;
        }

        GameObject gameObject = handler.GetGameObject(item.Node);
        if (gameObject == null)
        {
            return;
        }

        if (gameObject.TryGetComponent<Enemy>(out _))
        {
            item.RowContainer.AddToClassList(k_EnemyUssClassName);
        }
    }
}

      EditorGUIUtility.isProSkin is true when the Editor uses the dark theme. OnBindView uses it to choose which style sheet to load.

    8. Save the script.

    The rows of enemies use the color that matches the Editor theme. To check the color in the other theme, change the Editor Theme setting in the General preferences.

    Change the icon of favorite GameObjects

    Each row in the Hierarchy window displays an icon that represents the type of item. You can replace the icon with your own image or a built-in icon. The following script displays a star icon for every GameObject that has the Favorite tag.

    For more information about tags, refer to Tags
    See in Glossary    .

    To change the icon of favorite GameObjects:

    1. Create a Favorite tag:
      1. In the Hierarchy window, select a GameObject.
      2. In the Inspector window, select the Tag dropdown.
      3. Select Add Tag.
      4. Select the plus icon to create a tag.
      5. Name the tag Favorite.

    2. In the HierarchyExtensions folder, right-click and select Create > UI Toolkit > Style Sheet (USS).

    3. Name the style sheet FavoriteIcon.uss.

    4. Open the style sheet and replace its contents with the following code:

      .hierarchy-item__icon.gameobject--favorite {
    background-image: resource("Icons/Favorite_colored.png");
}
    
.unity-collection-view__item--selected:hover:enabled .hierarchy-item__icon.gameobject--favorite,
.unity-collection-view:focus .unity-collection-view__item--selected .hierarchy-item__icon.gameobject--favorite {
    background-image: resource("Icons/Favorite_colored.png");
}

      The first rule sets the icon of rows that have the gameobject--favorite class. The second rule keeps the icon when the row is selected.

    5. In the same folder, right-click and select Create > Scripting > Empty C# Script.

    6. Name the script FavoriteIcon.cs.

    7. Open the script and replace its contents with the following code:

      using System;
using Unity.Hierarchy;
using Unity.Hierarchy.Editor;
using UnityEditor;
using UnityEditorInternal;
using UnityEngine;
using UnityEngine.UIElements;

public static class FavoriteIcon
{
    const string k_StyleSheetPath = "Assets/Editor/HierarchyExtensions/FavoriteIcon.uss";
    const string k_FavoriteTag = "Favorite";
    const string k_FavoriteUssClassName = "gameobject--favorite";

    [InitializeOnLoadMethod]
    static void Initialize()
    {
        HierarchyWindow.BindView += OnBindView;
        HierarchyWindow.BindViewItem += OnBindViewItem;
    }

    static void OnBindView(HierarchyWindow window, HierarchyView view)
    {
        StyleSheet styleSheet = AssetDatabase.LoadAssetAtPath<StyleSheet>(k_StyleSheetPath);
        view.styleSheets.Add(styleSheet);
    }

    static void OnBindViewItem(HierarchyWindow window, HierarchyView view, HierarchyViewItem item)
    {
        // The row can display a different item each time, so remove the class first.
        // Rows can also display scenes and other items that aren't GameObjects.
        item.Icon.RemoveFromClassList(k_FavoriteUssClassName);

        if (item.Handler is not HierarchyGameObjectHandler handler)
        {
            return;
        }

        GameObject gameObject = handler.GetGameObject(item.Node);
        if (gameObject == null)
        {
            return;
        }

        // CompareTag logs an error if the project doesn't define the tag.
        if (Array.IndexOf(InternalEditorUtility.tags, k_FavoriteTag) < 0)
        {
            return;
        }

        if (gameObject.CompareTag(k_FavoriteTag))
        {
            item.Icon.AddToClassList(k_FavoriteUssClassName);

            // The Hierarchy window sets the default icon as an inline style, which overrides
            // style sheets. Clear the inline style so that the icon from the USS class applies.
            item.Icon.style.backgroundImage = StyleKeyword.Null;
        }
    }
}

      The script contains the following parts:

      • Icon is the element that displays the icon of the row. The script adds the gameobject--favorite class to it.
      • The Hierarchy window sets the default icon as an inline style. Inline styles take precedence over style sheets, so the script clears the inline background image of favorite GameObjects.
      • GameObject.CompareTag logs an error if the project doesn’t define the tag, so the script first checks that the Favorite tag exists.

    8. Save the script.

    9. In the Hierarchy window, select a GameObject.

    10. In the Inspector window, set Tag to Favorite.

    GameObjects with the Favorite tag display a star icon in the Hierarchy window.
