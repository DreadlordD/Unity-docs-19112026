    Display custom tooltips in the Hierarchy window

    Display your own information when you hover over an item in the Hierarchy window. For example, you can attach notes to GameObjects in your scene and read them in the Hierarchy window without selecting each GameObject.

    By default, GameObjects in the Hierarchy window have a tooltip only while you search, when the tooltip displays the path of the GameObject, starting with its scene. To set your own tooltip, subscribe to the HierarchyWindow.GetTooltip event. The Unity Editor raises the event when you hover over an item, and passes the default tooltip text in a StringBuilder. After your event handler returns, the Editor displays the text that the StringBuilder contains.

    Prerequisites

    Before you begin, complete the following steps:

    • Disable the Use Legacy Hierarchy setting, if you enabled it. For more information, refer to Switch to the legacy Hierarchy window.
    • In the Project window, create the Assets/Scripts and Assets/Editor/HierarchyExtensions folders. The scripts on this page load their style sheets from Assets/Editor/HierarchyExtensions.

    Create the Notes component

    The scripts on this page display the text of a Notes component in the tooltip.

    To create the Notes component:

    1. In the Assets/Scripts folder, right-click and select Create > Scripting > Empty C# Script.

    2. Name the script Notes.cs.

    3. Open the script and replace its contents with the following code:

      using UnityEngine;

// Stores a note about a GameObject.
public class Notes : MonoBehaviour
{
    [TextArea(3, 10)]
    public string note;
}

    4. Save the script.

    5. In the Hierarchy window, select a GameObject.

    6. In the Inspector window, select Add Component > Scripts > Notes.

    7. In the Note field of the Notes component, enter some text.

    The selected GameObject now has a note. The scripts on this page ignore empty notes.

    Display a note as a tooltip

    The following script sets the tooltip of each GameObject that has a note.

    To display a note as a tooltip:

    1. In the Assets/Editor/HierarchyExtensions folder, right-click and select Create > Scripting > Empty C# Script.

    2. Name the script NotesTooltip.cs.

    3. Open the script and replace its contents with the following code:

      using System.Text;
using Unity.Hierarchy;
using Unity.Hierarchy.Editor;
using UnityEditor;
using UnityEngine;

public static class NotesTooltip
{
    [InitializeOnLoadMethod]
    static void Initialize()
    {
        HierarchyWindow.GetTooltip += OnGetTooltip;
    }

    // Runs when you hover over an item. The tooltip parameter contains the default tooltip text.
    static void OnGetTooltip(HierarchyWindow window, HierarchyView view, HierarchyViewItem item, StringBuilder tooltip, bool filtering)
    {
        if (item.Handler is not HierarchyGameObjectHandler handler)
        {
            return;
        }

        GameObject gameObject = handler.GetGameObject(item.Node);
        if (gameObject == null || !gameObject.TryGetComponent<Notes>(out Notes notes) || string.IsNullOrWhiteSpace(notes.note))
        {
            return;
        }

        // Replace the default tooltip with the note.
        tooltip.Clear();
        tooltip.Append("Note: ");
        tooltip.Append(notes.note);
    }
}

      OnGetTooltip returns without changes if the GameObject has no note, so other GameObjects keep the default tooltip. Otherwise, it clears the default tooltip and adds the note.

    4. Save the script.

    5. In the Hierarchy window, hover over a GameObject that has a note.

    The tooltip displays the note.

    Keep the default tooltip during a search

    When you search in the Hierarchy window, the default tooltip displays the path of each GameObject, starting with its scene. The path is useful, because search results don’t display parent GameObjects. The previous script clears the path. The filtering parameter of GetTooltip is true when the Hierarchy window displays search results.

    The following script keeps the default tooltip during a search and adds the note after it.

    To keep the default tooltip during a search:

    1. Replace the contents of NotesTooltip.cs with the following code:

      using System.Text;
using Unity.Hierarchy;
using Unity.Hierarchy.Editor;
using UnityEditor;
using UnityEngine;

public static class NotesTooltip
{
    [InitializeOnLoadMethod]
    static void Initialize()
    {
        HierarchyWindow.GetTooltip += OnGetTooltip;
    }

    static void OnGetTooltip(HierarchyWindow window, HierarchyView view, HierarchyViewItem item, StringBuilder tooltip, bool filtering)
    {
        if (item.Handler is not HierarchyGameObjectHandler handler)
        {
            return;
        }

        GameObject gameObject = handler.GetGameObject(item.Node);
        if (gameObject == null || !gameObject.TryGetComponent<Notes>(out Notes notes) || string.IsNullOrWhiteSpace(notes.note))
        {
            return;
        }

        if (filtering)
        {
            // During a search, keep the default tooltip and add the note after it.
            tooltip.Append("\nNote: ");
            tooltip.Append(notes.note);
        }
        else
        {
            tooltip.Clear();
            tooltip.Append("Note: ");
            tooltip.Append(notes.note);
        }
    }
}

    2. Save the script.

    3. In the Hierarchy window search field, enter the name of a GameObject that has a note.

    4. Hover over the GameObject in the search results.

    During a search, the tooltip displays the default tooltip followed by the note. When you clear the search, the tooltip displays only the note.

    Indicate which GameObjects have notes

    Tooltips appear only when you hover over an item. To indicate which GameObjects have a note without hovering, display an indicator over the item icon. OverlayIcon is an element over the icon of a row that you can use to indicate the state of an item, such as a prefab with a broken reference.

    To add an information icon over the icon of each GameObject that has a note:

    1. In the Assets/Editor/HierarchyExtensions folder, right-click and select Create > UI Toolkit > Style Sheet (USS).

    2. Name the style sheet NotesTooltip.uss.

    3. Open the style sheet and replace its contents with the following code:

      .hierarchy-item__notes-overlay {
    position: absolute;
    width: 100%;
    height: 100%;
    background-size: 8px 8px;
    background-position: top left;
    background-repeat: no-repeat;
    background-image: var(--unity-icons-console_entry_info_small);
}

      The style sheet places a small built-in information icon in the upper-left corner of the item icon.

    4. Replace the contents of NotesTooltip.cs with the following code:

      using System.Text;
using Unity.Hierarchy;
using Unity.Hierarchy.Editor;
using UnityEditor;
using UnityEngine;
using UnityEngine.UIElements;

public static class NotesTooltip
{
    const string k_StyleSheetPath = "Assets/Editor/HierarchyExtensions/NotesTooltip.uss";
    const string k_NotesOverlayUssClassName = "hierarchy-item__notes-overlay";

    [InitializeOnLoadMethod]
    static void Initialize()
    {
        HierarchyWindow.BindView += OnBindView;
        HierarchyWindow.BindViewItem += OnBindViewItem;
        HierarchyWindow.GetTooltip += OnGetTooltip;
    }

    static void OnBindView(HierarchyWindow window, HierarchyView view)
    {
        StyleSheet styleSheet = AssetDatabase.LoadAssetAtPath<StyleSheet>(k_StyleSheetPath);
        view.styleSheets.Add(styleSheet);
    }

    static void OnBindViewItem(HierarchyWindow window, HierarchyView view, HierarchyViewItem item)
    {
        if (item.Handler is not HierarchyGameObjectHandler handler)
        {
            item.OverlayIcon.Q(className: k_NotesOverlayUssClassName)?.RemoveFromHierarchy();
            return;
        }

        GameObject gameObject = handler.GetGameObject(item.Node);
        bool hasNote = TryGetNote(gameObject, out _);
        VisualElement notesOverlay = item.OverlayIcon.Q(className: k_NotesOverlayUssClassName);

        // Add an indicator over the icon of items that have a note. Remove any indicator
        // that a reused row kept from an item that has a note.
        if (hasNote && notesOverlay == null)
        {
            notesOverlay = new VisualElement();
            notesOverlay.AddToClassList(k_NotesOverlayUssClassName);
            item.OverlayIcon.Add(notesOverlay);
        }
        else if (!hasNote && notesOverlay != null)
        {
            notesOverlay.RemoveFromHierarchy();
        }
    }

    static void OnGetTooltip(HierarchyWindow window, HierarchyView view, HierarchyViewItem item, StringBuilder tooltip, bool filtering)
    {
        if (item.Handler is not HierarchyGameObjectHandler handler)
        {
            return;
        }

        GameObject gameObject = handler.GetGameObject(item.Node);
        if (!TryGetNote(gameObject, out string note))
        {
            return;
        }

        if (filtering)
        {
            tooltip.Append("\nNote: ");
            tooltip.Append(note);
        }
        else
        {
            tooltip.Clear();
            tooltip.Append("Note: ");
            tooltip.Append(note);
        }
    }

    static bool TryGetNote(GameObject gameObject, out string note)
    {
        note = null;
        if (gameObject == null || !gameObject.TryGetComponent<Notes>(out Notes notes) || string.IsNullOrWhiteSpace(notes.note))
        {
            return false;
        }

        note = notes.note;
        return true;
    }
}

      OnBindViewItem adds the indicator to OverlayIcon if the GameObject has a note, and removes any indicator that the row kept from an item it displayed before. Both event handlers use TryGetNote to read the note.

    5. Save the script.

    GameObjects that have a note display an information icon over their icon in the Hierarchy window, and display the note when you hover over them.

    The icon updates when the Hierarchy window binds the row again, for example when you expand or collapse a parent GameObject or scroll the row into view. If you add or clear a note, the icon can be out of date until then. The tooltip always shows the current note.
