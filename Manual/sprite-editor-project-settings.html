    Sprite Editor project settings reference

    View and edit the settings that override the field locks an asset importer sets in the Sprite Editor window.

    To open these settings, go to Edit > Project Settings > Sprite Editor.

    For information about the fields these settings affect, refer to Sprite Editor tab reference for the Sprite Editor window.

    Sprite Editor project settings

    The Sprite Editor category in the Project Settings window contains the following settings.

    Sprite Frame Module

    Important: Editing fields that the asset importer locks is deprecated. This setting is temporarily available, and Unity might remove it in a future version.

    The Sprite Frame Module section contains the following settings.

    Property Description
    Sprite Frame field edit lock override Overrides the field locks that the asset importer sets in the Sprite Editor tab. When you enable this setting, the Name, Position, Border, and Pivot options in the Locks dropdown become available for locked fields, so you can unlock those fields and edit their values in the Sprite overlay. Create/Delete also becomes available, so you can create and delete sprites. When you disable this setting, Unity grays out the options for fields that the asset importer locks, so you can’t edit them. Unity disables this setting by default.
