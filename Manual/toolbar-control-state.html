    Update a toolbar control when its state changes

    If a toolbar control represents a setting, such as whether the Scene view grid is visible, the control must display the current state of that setting. This includes changes that you make elsewhere in the Editor. Use this approach for toggles, dropdowns, and any control whose text, icon, or value depends on the state of the Unity Editor.

    The toolbar doesn’t read the state of your setting again on its own. A control keeps its original content and value until you call MainToolbar.Refresh. When you interact with a control, the Editor calls your callback with the new value. Your code then applies the change and calls MainToolbar.Refresh to tell the toolbar to redraw the control. The toolbar then calls your MainToolbarElement method again, which reads the current state.

    Create a toggle that refreshes itself

    The following script creates a toolbar toggle that shows or hides the Scene view grid when you select it. The toggle’s icon changes to indicate whether the grid is visible.

    To create the Scene view grid toggle:

    1. In the Assets/Editor folder, create an empty C# script called SceneGridToggle.cs.

    2. Replace the contents of the script with the following code:

      using UnityEditor;
using UnityEditor.Toolbars;
using UnityEngine;

public class SceneGridToggle
{
    const string k_Path = "Example/Scene Grid";

    [MainToolbarElement(k_Path, defaultDockPosition = MainToolbarDockPosition.Middle)]
    public static MainToolbarElement CreateGridToggle()
    {
        // Read the current state every time the toolbar asks for the control.
        SceneView sceneView = SceneView.lastActiveSceneView;
        bool showGrid = sceneView != null && sceneView.showGrid;

        string iconName = showGrid ? "scenevis_visible" : "scenevis_hidden";
        Texture2D icon = EditorGUIUtility.IconContent(iconName).image as Texture2D;
        MainToolbarContent content = new MainToolbarContent("Grid", icon, "Show or hide the Scene view grid");

        return new MainToolbarToggle(content, showGrid, OnToggleChanged);
    }

    static void OnToggleChanged(bool value)
    {
        // The toolbar doesn't read the grid state again on its own. Apply the new value,
        // then refresh the control so it reflects the change.
        if (SceneView.lastActiveSceneView != null)
        {
            SceneView.lastActiveSceneView.showGrid = value;
        }

        MainToolbar.Refresh(k_Path);
    }
}

      The script contains the following parts:

      • CreateGridToggle reads whether the grid is visible and chooses an icon to match. It passes the current value to MainToolbarToggle.
      • OnToggleChanged runs when you select the toggle. It shows or hides the grid, then calls MainToolbar.Refresh with the same path as the MainToolbarElement attribute. To avoid repeating the path in the attribute and the Refresh call, the script stores it in a constant.

    3. Save the script.

    4. In the Editor, right-click an empty area of the toolbar and select Example > Scene Grid to display the Grid toggle.

    5. Select the Grid toggle.

    The grid appears or disappears in the Scene view, and the icon of the Grid toggle changes to match.

    Respond to changes outside the toolbar

    The previous script refreshes the toggle only when you select it. If you show or hide the grid from the Scene view, the toggle displays an outdated state. To keep the toggle in sync with the Scene view grid, subscribe to an event that reports the change, and call MainToolbar.Refresh from the event handler.

    The following script updates the toggle when you change the grid from either the toolbar or the Scene view.

    To keep the toggle in sync with the Scene view:

    1. Replace the contents of SceneGridToggle.cs with the following code:

      using UnityEditor;
using UnityEditor.Toolbars;
using UnityEngine;

[InitializeOnLoad]
public class SceneGridToggle
{
    const string k_Path = "Example/Scene Grid (Synced)";

    static SceneGridToggle()
    {
        // Refresh the control when the grid changes outside the toolbar,
        // for example from the Scene view toolbar.
        SceneView.lastActiveSceneViewChanged += OnLastActiveSceneViewChanged;
        OnLastActiveSceneViewChanged(null, SceneView.lastActiveSceneView);
    }

    [MainToolbarElement(k_Path, defaultDockPosition = MainToolbarDockPosition.Middle)]
    public static MainToolbarElement CreateGridToggle()
    {
        SceneView sceneView = SceneView.lastActiveSceneView;
        bool showGrid = sceneView != null && sceneView.showGrid;

        string iconName = showGrid ? "scenevis_visible" : "scenevis_hidden";
        Texture2D icon = EditorGUIUtility.IconContent(iconName).image as Texture2D;
        MainToolbarContent content = new MainToolbarContent("Grid", icon, "Show or hide the Scene view grid");

        return new MainToolbarToggle(content, showGrid, OnToggleChanged);
    }

    static void OnToggleChanged(bool value)
    {
        if (SceneView.lastActiveSceneView != null)
        {
            SceneView.lastActiveSceneView.showGrid = value;
        }

        MainToolbar.Refresh(k_Path);
    }

    static void OnLastActiveSceneViewChanged(SceneView oldView, SceneView newView)
    {
        if (oldView != null)
        {
            oldView.gridVisibilityChanged -= OnGridVisibilityChanged;
        }
        if (newView != null)
        {
            newView.gridVisibilityChanged += OnGridVisibilityChanged;
        }

        MainToolbar.Refresh(k_Path);
    }

    static void OnGridVisibilityChanged(bool visible)
    {
        MainToolbar.Refresh(k_Path);
    }
}

      The InitializeOnLoad attribute runs the static constructor when the Editor loads the script. The constructor subscribes to SceneView.gridVisibilityChanged on the active Scene view. It also subscribes to SceneView.lastActiveSceneViewChanged to move the subscription when the active Scene view changes, and calls the handler once so that it subscribes to the Scene view that’s already open.

    2. Save the script.

    3. In the Editor, right-click an empty area of the toolbar and select Example > Scene Grid (Synced) to display the Grid toggle.

    4. In the Scene view, select Toggle grid visibility in the Grid and Snap overlay.

    The Grid toggle now updates when you change the grid from either the toolbar or the Scene view.

    You can use the same approach for other controls. For example, to create a MainToolbarDropdown that displays the selected item, store the selection in a field and call MainToolbar.Refresh when the selection changes.
