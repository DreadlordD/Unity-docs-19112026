    Add a scene selector dropdown to the toolbar

    If you often move between scenes while you work, add a dropdown to the Unity Editor toolbar that lists the scenes in your project. Select a scene from the list to open it, without having to find it in the Project window. The dropdown also displays the name of the active scene.

    A toolbar dropdown is a MainToolbarDropdown. It displays text and an icon like a button. When you select it, the Editor calls your method and passes the position of the dropdown, so your code can open a menu at the dropdown. This page first creates a dropdown that opens scenes, then keeps the scene name up to date, and finally adds support for Play mode.

    Prerequisites

    • Complete Add a custom button to the toolbar.

    Create a scene selector dropdown

    The following script creates a dropdown that displays the name of the active scene and lists every scene in the Assets folder. This first version doesn’t work in Play mode, and it doesn’t update its text when the active scene changes.

    To create a dropdown that opens the scenes in your project:

    1. In the Assets/Editor folder, create an empty C# script called SceneSelectorDropdown.cs.

    2. Replace the contents of the script with the following code:

      using System.IO;
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEditor.Toolbars;
using UnityEngine;
using UnityEngine.SceneManagement;

public class SceneSelectorDropdown
{
    [MainToolbarElement("Example/Scene Selector", defaultDockPosition = MainToolbarDockPosition.Middle)]
    public static MainToolbarElement CreateSceneSelectorDropdown()
    {
        // A new scene that you haven't saved yet has no name.
        string activeSceneName = SceneManager.GetActiveScene().name;
        if (string.IsNullOrEmpty(activeSceneName))
        {
            activeSceneName = "Untitled";
        }

        Texture2D icon = EditorGUIUtility.IconContent("UnityLogo").image as Texture2D;
        MainToolbarContent content = new MainToolbarContent(activeSceneName, icon, "Open a scene in the project");
        return new MainToolbarDropdown(content, ShowDropdownMenu);
    }

    static void ShowDropdownMenu(Rect dropdownRect)
    {
        GenericMenu menu = new GenericMenu();
        string activeScenePath = SceneManager.GetActiveScene().path;

        // Find every scene asset in the Assets folder.
        string[] sceneGuids = AssetDatabase.FindAssets("t:SceneAsset", new string[] { "Assets" });
        if (sceneGuids.Length == 0)
        {
            menu.AddDisabledItem(new GUIContent("No scenes in project"));
        }

        foreach (string sceneGuid in sceneGuids)
        {
            string scenePath = AssetDatabase.GUIDToAssetPath(sceneGuid);
            string sceneName = Path.GetFileNameWithoutExtension(scenePath);

            // Display a check mark next to the active scene.
            bool isActiveScene = scenePath == activeScenePath;
            menu.AddItem(new GUIContent(sceneName), isActiveScene, () => OpenScene(scenePath));
        }

        menu.DropDown(dropdownRect);
    }

    static void OpenScene(string scenePath)
    {
        // Ask whether to save changes to the open scenes before Unity closes them.
        if (EditorSceneManager.SaveCurrentModifiedScenesIfUserWantsTo())
        {
            EditorSceneManager.OpenScene(scenePath);
        }
    }
}

      The script contains the following parts:

      • CreateSceneSelectorDropdown reads the name of the active scene and uses it as the text of the dropdown. It passes the ShowDropdownMenu method to MainToolbarDropdown.
      • ShowDropdownMenu uses AssetDatabase.FindAssets to find every scene in the Assets folder, and adds each scene to a GenericMenu. It then calls GenericMenu.DropDown with the position that the Editor passes in, so the menu opens at the dropdown.
      • OpenScene calls EditorSceneManager.SaveCurrentModifiedScenesIfUserWantsTo to ask whether to save your changes, then opens the selected scene with EditorSceneManager.OpenScene.

    3. Save the script.

    4. In the Editor, right-click an empty area of the toolbar and select Example > Scene Selector to display the scene selector dropdown.

    5. Select the dropdown, and then select a scene.

    The scene selector dropdown appears in the middle section of the toolbar, and the Editor opens the scene that you select. The dropdown still displays the name of the previous scene.

    Update the dropdown when the active scene changes

    The toolbar doesn’t read the active scene again on its own. To display the name of the new scene, your script must call MainToolbar.Refresh when the active scene changes. For more information about how to refresh a control, refer to Update a toolbar control when its state changes.

    The following script refreshes the dropdown when the active scene changes and when you save a scene.

    To keep the scene name up to date:

    1. Replace the contents of SceneSelectorDropdown.cs with the following code:

      using System.IO;
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEditor.Toolbars;
using UnityEngine;
using UnityEngine.SceneManagement;

[InitializeOnLoad]
public class SceneSelectorDropdown
{
    const string k_Path = "Example/Scene Selector (Synced)";

    static SceneSelectorDropdown()
    {
        // Refresh the dropdown when the active scene changes or when you save a scene,
        // so the dropdown always displays the name of the active scene.
        EditorSceneManager.activeSceneChangedInEditMode += OnActiveSceneChanged;
        EditorSceneManager.sceneSaved += OnSceneSaved;
    }

    [MainToolbarElement(k_Path, defaultDockPosition = MainToolbarDockPosition.Middle)]
    public static MainToolbarElement CreateSceneSelectorDropdown()
    {
        string activeSceneName = SceneManager.GetActiveScene().name;
        if (string.IsNullOrEmpty(activeSceneName))
        {
            activeSceneName = "Untitled";
        }

        Texture2D icon = EditorGUIUtility.IconContent("UnityLogo").image as Texture2D;
        MainToolbarContent content = new MainToolbarContent(activeSceneName, icon, "Open a scene in the project");
        return new MainToolbarDropdown(content, ShowDropdownMenu);
    }

    static void ShowDropdownMenu(Rect dropdownRect)
    {
        GenericMenu menu = new GenericMenu();
        string activeScenePath = SceneManager.GetActiveScene().path;

        string[] sceneGuids = AssetDatabase.FindAssets("t:SceneAsset", new string[] { "Assets" });
        if (sceneGuids.Length == 0)
        {
            menu.AddDisabledItem(new GUIContent("No scenes in project"));
        }

        foreach (string sceneGuid in sceneGuids)
        {
            string scenePath = AssetDatabase.GUIDToAssetPath(sceneGuid);
            string sceneName = Path.GetFileNameWithoutExtension(scenePath);
            bool isActiveScene = scenePath == activeScenePath;
            menu.AddItem(new GUIContent(sceneName), isActiveScene, () => OpenScene(scenePath));
        }

        menu.DropDown(dropdownRect);
    }

    static void OpenScene(string scenePath)
    {
        if (EditorSceneManager.SaveCurrentModifiedScenesIfUserWantsTo())
        {
            EditorSceneManager.OpenScene(scenePath);
        }
    }

    static void OnActiveSceneChanged(Scene previousScene, Scene newScene)
    {
        MainToolbar.Refresh(k_Path);
    }

    static void OnSceneSaved(Scene scene)
    {
        MainToolbar.Refresh(k_Path);
    }
}

      The InitializeOnLoad attribute runs the static constructor when the Editor loads the script. The constructor subscribes to the following events, and each event handler calls MainToolbar.Refresh:

      • EditorSceneManager.activeSceneChangedInEditMode: The Editor raises this event when the active scene changes, for example when you open a scene from the dropdown or from the Project window.
      • EditorSceneManager.sceneSaved: The Editor raises this event when you save a scene, for example when you save a new scene and give it a name.

    2. Save the script.

    3. In the Editor, right-click an empty area of the toolbar and select Example > Scene Selector (Synced) to display the scene selector dropdown.

    4. Open a different scene from the dropdown or from the Project window.

    The dropdown now displays the name of the scene that you opened.

    Change scenes in Play mode

    In Play mode, EditorSceneManager.OpenScene isn’t available. Instead, use SceneManager.LoadScene to load the scene in the same way as your application does at runtime. SceneManager can load only the scenes in the scene list of the active build profile. For more information, refer to Manage scenes in a build.

    The following script loads the selected scene with SceneManager.LoadScene in Play mode, and opens it with EditorSceneManager.OpenScene outside Play mode.

    To change scenes in Play mode:

    1. Replace the contents of SceneSelectorDropdown.cs with the following code:

      using System.IO;
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEditor.Toolbars;
using UnityEngine;
using UnityEngine.SceneManagement;

[InitializeOnLoad]
public class SceneSelectorDropdown
{
    const string k_Path = "Example/Scene Selector (Play mode)";

    static SceneSelectorDropdown()
    {
        EditorSceneManager.activeSceneChangedInEditMode += OnActiveSceneChanged;
        EditorSceneManager.sceneSaved += OnSceneSaved;

        // Also refresh the dropdown when the active scene changes in Play mode.
        SceneManager.activeSceneChanged += OnActiveSceneChanged;
    }

    [MainToolbarElement(k_Path, defaultDockPosition = MainToolbarDockPosition.Middle)]
    public static MainToolbarElement CreateSceneSelectorDropdown()
    {
        string activeSceneName = SceneManager.GetActiveScene().name;
        if (string.IsNullOrEmpty(activeSceneName))
        {
            activeSceneName = "Untitled";
        }

        Texture2D icon = EditorGUIUtility.IconContent("UnityLogo").image as Texture2D;
        MainToolbarContent content = new MainToolbarContent(activeSceneName, icon, "Open a scene in the project");
        return new MainToolbarDropdown(content, ShowDropdownMenu);
    }

    static void ShowDropdownMenu(Rect dropdownRect)
    {
        GenericMenu menu = new GenericMenu();
        string activeScenePath = SceneManager.GetActiveScene().path;

        string[] sceneGuids = AssetDatabase.FindAssets("t:SceneAsset", new string[] { "Assets" });
        if (sceneGuids.Length == 0)
        {
            menu.AddDisabledItem(new GUIContent("No scenes in project"));
        }

        foreach (string sceneGuid in sceneGuids)
        {
            string scenePath = AssetDatabase.GUIDToAssetPath(sceneGuid);
            string sceneName = Path.GetFileNameWithoutExtension(scenePath);
            bool isActiveScene = scenePath == activeScenePath;
            menu.AddItem(new GUIContent(sceneName), isActiveScene, () => SwitchScene(scenePath));
        }

        menu.DropDown(dropdownRect);
    }

    static void SwitchScene(string scenePath)
    {
        if (EditorApplication.isPlaying)
        {
            // In Play mode, Unity can load only the scenes in the scene list
            // of the active build profile.
            string sceneName = Path.GetFileNameWithoutExtension(scenePath);
            if (Application.CanStreamedLevelBeLoaded(sceneName))
            {
                SceneManager.LoadScene(sceneName);
            }
            else
            {
                Debug.LogError($"Add the {sceneName} scene to the scene list of the active build profile to load it in Play mode.");
            }
        }
        else if (EditorSceneManager.SaveCurrentModifiedScenesIfUserWantsTo())
        {
            EditorSceneManager.OpenScene(scenePath);
        }
    }

    static void OnActiveSceneChanged(Scene previousScene, Scene newScene)
    {
        MainToolbar.Refresh(k_Path);
    }

    static void OnSceneSaved(Scene scene)
    {
        MainToolbar.Refresh(k_Path);
    }
}

      The script contains the following changes:

      • SwitchScene checks whether the Editor is in Play mode. In Play mode, it uses Application.CanStreamedLevelBeLoaded to check that the scene is in the scene list, and then loads the scene with SceneManager.LoadScene. If the scene isn’t in the scene list, the script logs an error in the Console window. In Edit mode, SwitchScene opens the scene in the same way as the previous script.
      • The constructor also subscribes to SceneManager.activeSceneChanged, so the dropdown updates when the active scene changes in Play mode.

    2. Save the script.

    3. In the Editor, right-click an empty area of the toolbar and select Example > Scene Selector (Play mode) to display the scene selector dropdown.

    4. Enter Play mode.

    5. Select the dropdown, and then select a scene in the scene list of the active build profile.

    The Editor loads the scene, and the dropdown displays its name.
